# 植物の葉のつき方

小学校・中学校・高等学校の理科向けに、葉序・葉形・葉脈を組み立てて観察するWeb教材です。

**公開URL:** https://scd-ku.github.io/hanotsukikata/

## v18 — 新しい植物

見本植物は **30種類** です。今回追加したのは以下の4種類です。

- **ヒマワリ（Helianthus annuus）** — 下位節は対生、上位節は互生。大きな鋸歯のある心形の葉と基部の主要脈。
- **エンドウ（Pisum sativum）** — 互生する羽状複葉。3対の小葉と先端の巻きひげ、大型托葉を模式化。
- **サツキ（Rhododendron indicum）** — 木本性低木。枝先に密集しやすい細長い互生葉と細かな鋸歯。
- **スギ（Cryptomeria japonica）** — 裸子植物。短い針状葉が枝にらせん状に並ぶ様子を模式化。

植物形態の出典はアプリ内のヘルプに記載しました。葉序の分数は文献確認値・模式値・未確定を区別しています。

## 主な機能

- 「種子植物」「葉序」「葉形」の3分類で選べるポップアップ
- 分類切り替え時の移動軌跡とスローアニメーション
- ポップアップの位置とサイズの変更
- 3D茎の節へのスナップ、葉脈、ふりがな、全画面表示、自動保存
- タイトル左のQRアイコンによる公開URLの表示
- 国立科学博物館の葉脈標本データベースへの検索ページリンク（結果URLの直接生成は未検証）

`index.html` 単体で動作します。GitHub Pages の公開元を `main` / `(root)` に設定してください。
