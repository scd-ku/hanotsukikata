# 植物の葉のつき方

小学校・中学校・高等学校の理科向けに、葉序・葉形・葉脈を組み立てて観察するWeb教材です。

**公開URL:** https://scd-ku.github.io/hanotsukikata/

## v28 — エンジュ、ケヤキ、カツラ、ニッキ

3D見本を **42種類から46種類** に増やしました。右側の類似植物候補は50分類群の参考データを扱います。

- **エンジュ（Styphnolobium japonicum）**：マメ科。互生、奇数羽状複葉。13小葉（6対と先端の1枚）を教材モデルとして表現。旧学名 *Sophora japonica*。
- **ケヤキ（Zelkova serrata）**：ニレ科。2列互生、左右がやや非対称な葉の基部、縁の鋸歯、直線的な側脈。「ケヤキ型」葉身を追加。
- **カツラ（Cercidiphyllum japonicum）**：カツラ科。長枝では対生、短枝では単独の葉がつく。丸い心形葉と波状の鈍鋸歯・基部から放射状の葉脈。「カツラ型」葉身を追加。
- **ニッキ（ニッケイ、Cinnamomum sieboldii）**：クスノキ科。互生の細長い全縁葉、葉の基部付近から伸びる三行脈。日本の香料植物であり、シナモン類の別種とは区別。

新しい4種類は「種子植物の分類」「葉序で分類」「葉形で分類」すべてに追加しました。個別の葉序の分数は文献確認値・配置型・模式値・適用外を区別しています。出典はアプリ内ヘルプにも記載しています。

参考：NC State Extension、World Flora Online、林野庁（カツラ）、日本メディカルハーブ協会（ニッケイ）。3D形状は教育用の近似モデルです。

## v27 — ミモザ、アカシア、ポプラ、ヒノキ

見本植物は **42種類** です。今回追加したのは次の4種類です。エンドウは既存の見本を維持し、重複登録していません。

- **ミモザ（フサアカシア、Acacia dealbata）**：互生する二回羽状複葉。多くの羽片に細い小葉が並ぶ模式モデル。
- **アカシア（ギンヨウアカシア、Acacia baileyana）**：互生する銀青緑色の二回羽状複葉。ミモザより羽片の対数を少なくして比較できるようにしました。
- **ポプラ（セイヨウハコヤナギ、Populus nigra 'Italica'）**：互生する三角状の単葉、鋸歯と比較的長い葉柄。三角形の葉身輪郭を新規追加。
- **ヒノキ（Chamaecyparis obtusa）**：裸子植物。扁平な小枝に重なる十字対生の鱗片葉。裏面のY字形の白い気孔帯は微細形態のため省略。

「アカシア」は広い呼称のため、今回の教材では **ギンヨウアカシア（Acacia baileyana）** と明示しています。ニセアカシア（Robinia pseudoacacia）とは異なる種です。ミモザは **フサアカシア（Acacia dealbata）** を採用しています。

これらの形態は教材用の近似表現です。葉序の分数は文献確認値と教材モデル値を区別しています。

## v26 — 左右メニューを収納できる3D画面

- 左側の「葉の設定」と右側の「植物を探す」を、それぞれ3D画面端の縦タブで独立して開閉できます。
- デスクトップでは閉じたメニューの幅だけ中央の3D表示領域が広がります。
- iPad・スマートフォン相当の画面では、メニューを左右から出し入れする引き出しとして表示します。一方を開くと他方は閉じます。
- 画面の暗い部分を押すかEscキーでメニューを閉じられます。
- メニューの開閉状態は端末のブラウザに保存します（広い画面と小さな画面で個別に記憶）。
- 既存の未接続グレー葉、真上・真下からの視点、分類ポップアップ、SVG保存は維持しました。

## v25 — パレットからの未接続葉と視点の拡張

- パレットから取り出した時点で、葉の形がグレーで表示されます。
- 茎の節につけなくても3D空間の任意の位置に置けます。グレーのまま、視点を回転しても同じ位置に保持されます。
- 未接続の葉を再度ドラッグして移動したり、茎に近づけて接続したりできます。接続すると緑色に変化します。
- 接続済みの葉も、節から離してグレーの未接続葉に戻せます。
- 未接続の葉は植物の葉序・同定候補の判定には含めません。
- 未接続状態は自動保存・JSON入出力・複製に対応します。
- 3Dの真上・真下視点ボタンと、上下の広い回転範囲を追加しました。
- 分類切り替えアニメーションは維持し、移動軌跡の線は表示しません。

## v23 — ミント・バジル・キョウチクトウ・モクレンを追加

見本は **38種類** になりました。

- **ミント（スペアミント；Mentha spicata）**：対生、細長い卵状披針形の葉、明瞭な鋸歯、羽状脈。
- **バジル（Ocimum basilicum）**：対生、幅広い卵形から楕円形の葉、全縁～浅い鋸歯、羽状脈。
- **キョウチクトウ（Nerium oleander）**：同一節に3枚つく3輪生、細長い全縁葉、中央の主脈から多数出るほぼ平行な側脈。**全草に毒性があります**。
- **モクレン（Magnolia liliiflora）**：互生、倒卵形～楕円状卵形の全縁葉、羽状脈。現代のAPG分類ではモクレン類（magnoliids）で真正双子葉類とは異なります。

各植物の葉序の分数、形態の参考資料、分類上の注意点はアプリのヘルプを参照してください。対生・輪生に互生の分数は割り当てず、モクレンの2/5は模式値として区別しています。

## 主な機能

- 38種類の見本植物、葉序・葉形・種子植物による分類ポップアップ
- 葉と茎の前後関係を考慮した3D表示、節への自動スナップ
- 葉を右クリック／長押しして輪郭・葉柄・葉脈のSVGを書き出し
- 葉形に応じた設定項目の切り替え、ふりがな、全画面表示、自動保存
- 分類切り替え時に植物名だけが滑らかに移動するスローアニメーション（軌跡線なし）、ポップアップの位置移動・リサイズ
- タイトル左のQRアイコンによる公開URL表示

`index.html` 単体で動作します。GitHub Pages の公開元を `main` / `(root)` に設定してください。

**注意:** 植物の形態は教育用の近似モデルです。キョウチクトウなど有毒植物の授業での実物観察には十分注意してください。
