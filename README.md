# 植物の葉のつき方

小学校・中学校・高等学校の理科向けに、葉序・葉形・葉脈を組み立てて観察するWeb教材です。

**公開URL:** https://scd-ku.github.io/hanotsukikata/

## v23 — ミント・バジル・キョウチクトウ・モクレンを追加

見本は **38種類** になりました。

- **ミント（スペアミント；Mentha spicata）**：対生、細長い卵状披針形の葉、明瞭な鋸歯、羽状脈。
- **バジル（Ocimum basilicum）**：対生、幅広い卵形から楕円形の葉、全縁～浅い鋸歯、羽状脈。
- **キョウチクトウ（Nerium oleander）**：同一節に3枚つく3輪生、細長い全縁葉、中央の主脈から多数出るほぼ平行な側脈。**全草に毒性があります**。
- **モクレン（Magnolia liliiflora）**：互生、倒卵形～楕円状卵形の全縁葉、羽状脈。現代のAPG分類ではモクレン類（magnoliids）で真正双子葉類とは異なります。

各植物の葉序の分数、形態の参考資料、分類上の注意点はアプリのヘルプを参照してください。対生・輪生に互生の分数は割り当てず、モクレンの2/5は模式値として区別しています。

## 主な機能

- 38種類の見本植物、葉序・葉形・種子植物による分類ポップアップ
- 葉と茎の前後関係を考慮した3D表示、節への自動スナップ
- 葉を右クリック／長押しして輪郭・葉柄・葉脈のSVGを書き出し
- 葉形に応じた設定項目の切り替え、ふりがな、全画面表示、自動保存
- 分類切り替え時に植物名だけが滑らかに移動するスローアニメーション（軌跡線なし）、ポップアップの位置移動・リサイズ
- タイトル左のQRアイコンによる公開URL表示

`index.html` 単体で動作します。GitHub Pages の公開元を `main` / `(root)` に設定してください。

**注意:** 植物の形態は教育用の近似モデルです。キョウチクトウなど有毒植物の授業での実物観察には十分注意してください。
