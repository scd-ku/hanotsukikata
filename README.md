# 植物の葉のつき方

小学校・中学校・高等学校の理科向けに、葉序・葉形・葉脈を組み立てて観察するWeb教材です。

**公開URL:** https://scd-ku.github.io/hanotsukikata/

## 主な機能

- 26種類の見本植物（ツバキ・サザンカを含む）
- 「種子植物」「葉序」「葉形」の3通りに分類できるポップアップ
- 分類切り替え時の移動軌跡と約3秒のスローアニメーション（時間差付き）
- 分類ポップアップ上部をドラッグして表示位置を移動。上部をダブルクリックすると中央へ戻ります（画面外への移動は制限）
- ポップアップ右下の取っ手で幅・高さを変更。ダブルクリックで初期サイズに戻ります
- 茎の描画を連続した線に変更し、竹の節のように見えていた線分の継ぎ目を除去
- 節の位置は非表示ですが、葉の取り付け時には最も近い節へ自動スナップします
- 3Dモデル、葉脈、ふりがな、全画面表示、自動保存
- タイトル左のQRアイコンから公開URLのQRコードを表示

`index.html` 単体で動作します。GitHub Pagesの公開元を `main` / `root` に設定してください。

## 資料リンクについて

葉脈標本データベースの ↗ は国立科学博物館の検索ページへ移動します。植物名ごとの検索結果への直接リンクは未検証です。
