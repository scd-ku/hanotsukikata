# 植物の葉のつき方

小学校・中学校・高等学校の理科向けに、葉序・葉形・葉脈を組み立てて観察するWeb教材です。

**公開URL:** https://scd-ku.github.io/hanotsukikata/

## 主な機能

- 26種類の見本植物（ツバキ・サザンカを含む）
- 「種子植物」「葉序」「葉形」の3通りに分類できるポップアップ
- 分類切り替え時の移動軌跡と約3秒のスローアニメーション（時間差付き）
- ポップアップ右下の取っ手で幅・高さを変更（ダブルクリックで初期サイズに戻す）
- 葉を節にスナップして組み立てる3Dモデル、葉脈、ふりがな、全画面表示、自動保存
- タイトル左のQRアイコンから公開URLのQRコードを表示

`index.html` 単体で動作します。GitHub Pagesの公開元を `main` / `root` に設定してください。

## 資料リンクについて

葉脈標本データベースの ↗ は国立科学博物館の**検索ページ**へ移動します。検索語は植物名です。検索結果への直接リンクは未検証です。
