# 植物の葉のつき方

小学校・中学校・高等学校の理科向けに、葉序・葉形・葉脈を組み立てて観察するWeb教材です。

**公開URL:** https://scd-ku.github.io/hanotsukikata/

## v21 — 選択した葉のSVG書き出し

3Dモデル上の葉を**右クリック**（iPadでは**長押し**）し、「SVGで保存（葉・葉柄・葉脈）」を選ぶと、選択した葉を正面から見た編集可能なSVGファイルとして保存します。

- 葉身と葉柄を結合した**一つの閉じた輪郭パス**を出力します。複葉は小葉・葉軸・主葉柄を結合して外周を表現します。
- 葉脈は線幅を持った**独立した閉じたパス**で保存し、輪郭とは別のSVGグループで編集できます。
- 現在の葉の形、鋸歯、葉柄、切れ込み、葉脈、色などの設定を反映します。
- SVGは模式的な正面図で、3Dカメラのスクリーンショットや実物大の実測標本ではありません。
- 34種類の見本でSVG生成を検証しました。SVGはHTML内の標準ブラウザ機能のみで作成されます。

## 主な機能

- 34種類の見本植物、葉序・葉形・種子植物による分類ポップアップ
- 分類切り替え時の移動軌跡とスローアニメーション、ポップアップ移動・リサイズ
- 3D茎の節への自動スナップ、葉脈、ふりがな、全画面表示、自動保存
- タイトル左のQRアイコンによる公開URLの表示
- 国立科学博物館の葉脈標本データベースへのリンク

`index.html` 単体で動作します。GitHub Pages の公開元を `main` / `(root)` に設定してください。

**注意:** 植物形態は教育用の近似モデルです。葉序の分数は文献確認値と教材モデル値を区別しています。
