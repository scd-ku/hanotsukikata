# 植物の葉のつき方

小学校・中学校・高等学校の理科向けに、葉序・葉形・葉脈を組み立てて観察するWeb教材です。

**公開URL:** https://scd-ku.github.io/hanotsukikata/

## v19 — 葉柄の修正と植物の追加

見本植物は **34種類** です。今回追加した4種類：

- **ブナ（Fagus crenata）** — 2列互生、波状の鈍鋸歯、7〜11対の側脈。ブナ型の専用輪郭と葉脈。
- **セイタカアワダチソウ（Solidago altissima）** — 互生、披針形、3本の目立つ葉脈、低い鋸歯。
- **ススキ（Miscanthus sinensis）** — 2列互生、葉鞘をもつ細長い葉、平行脈。
- **ツツジ（Rhododendron kaempferi）** — ヤマツツジを代表例とし、枝先に集まる小形の互生葉を模式化。

**ウルシの葉柄の修正:** 複葉の主葉柄が茎の節と葉軸の間で途切れていたので、接続する線を追加しました。エンドウなどの複葉も共通の修正が適用されます。茎の節への自動スナップは維持しています。

前版で追加したヒマワリ・エンドウ・サツキ・スギも引き続き利用できます。

## 主な機能

- 「種子植物」「葉序」「葉形」の3分類で選べるポップアップ（位置移動・サイズ変更）
- 分類切り替え時の移動軌跡とスローアニメーション
- 3D茎の節へのスナップ、葉脈、ふりがな、全画面表示、自動保存
- タイトル左のQRアイコンによる公開URLの表示
- 国立科学博物館の葉脈標本データベースへの検索ページリンク（結果URLの直接生成は未検証）

`index.html` 単体で動作します。GitHub Pages の公開元を `main` / `(root)` に設定してください。

**注意:** モデルは教育用の形態近似で、葉の毛などの微細構造は省略しています。葉序の分数は文献確認値と教材モデル値を区別しています。
