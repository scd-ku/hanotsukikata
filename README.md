# 植物の葉のつき方

小学校・中学校・高等学校の理科向けに、葉序・葉形・葉脈を組み立てて観察するWeb教材です。

**公開URL:** https://scd-ku.github.io/hanotsukikata/

## v22 — 葉と茎の遮蔽（前後関係）を改善

- 以前は茎を先に描き、葉全体の平均奥行きで重なりを判定していたため、茎の**奥にある葉が手前に表示される**ことがありました。
- 葉身の投影輪郭と茎が重なる地点で、**茎と葉の奥行きを直接比較**する処理を追加しました。
- 茎が手前にある重なり部分のみ、連続した茎の描画を前面へ復元します。葉が手前の場合は葉をそのまま表示します。
- 葉柄、複葉の葉軸、エンドウの巻きひげも前後関係の判定対象です。
- 視点を回転すると判定が更新されます。
- 茎の節への自動スナップ、SVG書き出し、34種類の見本はそのまま利用できます。

## 主な機能

- 34種類の見本植物、葉序・葉形・種子植物による分類ポップアップ
- 葉形に応じた調整項目の表示、複葉の接続位置修正
- 右クリック／長押しから、葉・葉柄・葉脈を閉じた輪郭パスのSVGとして保存
- 分類切り替え時の移動軌跡とスローアニメーション、ポップアップ移動・リサイズ
- 3D茎の節への自動スナップ、葉脈、ふりがな、全画面表示、自動保存
- タイトル左のQRアイコンによる公開URLの表示

`index.html` 単体で動作します。GitHub Pagesの公開元を `main` / `(root)` に設定してください。

**注意:** 植物形態は教育用の近似モデルです。葉序の分数は文献確認値と教材モデル値を区別しています。
